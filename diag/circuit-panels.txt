# Every CIRCUIT panel the note draws, and the Lean statement `diag-export --circuit` must draw it
# from.  The PANELS are the obligations: one line per `#cpanel` the note emits, in the note's own
# document order, so a panel with no declaration behind it is a line marked `-` and reported as
# NO-DECL rather than silently skipped, and deleting a line cannot make `scripts/circuit-check`
# pass — the gate loops over the note's panels and asks this file for each one's record.
#
#   <selector> | <the display's label> | <the panel's own `cert: expect:`>
#
# The selector is `<full Lean name>.lhs` / `.rhs` (or `.lhs.inl`, `#binder.lhs`), as
# `./scripts/diag-export --circuit` takes it — never the note's `lean:` marker spelling, which is
# `<module>.<name as its file writes it>` and no declaration name.
#
# WHY THE MAPPING IS AUTHORED AND NOT DERIVED.  A display's `lean:` marker lives in a TYPST COMMENT,
# which the compiler discards before anything can query it, so no typed reader can see it and the
# note-panel → declaration mapping cannot be computed: it is written here by hand, once, the way
# `diag/cd-panels.txt` names its selectors.  What IS typed is everything the gate then does: the
# panel list and each panel's cert come from `typst query … metadata` (`cpanel` emits one
# `(kind: "circuit", cert: …)` per panel), the note's own picture is rebuilt from that cert by
# `scripts/circuit`, and the two pictures are held to each other as SVG path data.
#
# A `-` line means the panel draws a STEP of a calculation — an intermediate term of a `vstep`
# chain — which is no declaration's statement and so has nothing to generate from.  It becomes a
# real obligation the moment that step gets a lemma of its own.
#
# The side, and the ARM.  A row of a proof table carries the marker of the law whose left side it
# is, so `.lhs` is the default; a row that is the law's other side takes `.rhs`, and a row that
# draws ONE ARM of a bracket — the note's `vstep` chains work on the cons arm and leave the nil arm
# to the formula — takes `.lhs.inr` / `.rhs.inr`, because `.lhs` alone draws the whole case split.
# Which one a line takes is settled against the note's own panel: the exe's tree and the note's
# must agree in top-level node kind and in port arity before a line names that selector, and a row
# no side or arm reaches keeps `.lhs` and shows up as a DIFF rather than as a silently-passing
# wrong picture.
