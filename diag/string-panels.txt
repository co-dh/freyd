# Every Hinze-Marsden panel `diag/allegory-axioms.typ` draws, and the Lean statement
# `diag-export --string` must draw the same picture from.  ONE LINE PER DISPLAY, in the form both
# manifests take and `scripts/panels.py` is the one reader of — three columns cut at ` | `:
#
#   <selector per panel>   one `diag-export --string` selector for each panel of the display, in the
#                          order the display draws them, `-` where no declaration is cited; a `#`
#                          comment after the third column names the candidates a `-` line has.
#   <the display's name>   its `#disp` LABEL (`thin-up`, written without the angle brackets), never
#                          its number: a number moves with every heading — `14.1.1x` became `14.1.2x`
#                          by hand this week — and a manifest keyed by one then answers for the wrong
#                          display without saying so.  The number is looked up from the label, in the
#                          `kind: "disp"` metadata `note-style.typ` emits beside each display.  A
#                          display the note leaves UNLABELLED has no name to key by and keys by its
#                          number; `scripts/string-check` reports those, since they are exactly the
#                          rows the next heading change can still break.
#   <what its panels draw> each panel's `cert: expect`, joined by ` = `
#
# THE DISPLAYS ARE THE OBLIGATIONS.  `scripts/string-check` enumerates the note's panels from
# `typst query` and fails on a display no line here names, so a picture cannot go unchecked by being
# left out, and deleting a line cannot make the gate pass.  A panel whose selector is `-` is
# reported NO-DECL: an obligation with no record, not a silent skip.
#
# The selector column is STATIC and was authored once.  A display's `lean:` marker is a Typst
# comment, so `typst query` cannot see it; the markers were read through `scripts/cite-cover`'s own
# note reader and resolved to full Lean names through the index.  A display carrying one marker per
# pair of panels took `<decl>.lhs`, `<decl>.rhs`; every other shape was left `-` with its candidates
# in the comment, because which side of which declaration a panel of a proof CHAIN draws is a
# judgement, not a derivation.
