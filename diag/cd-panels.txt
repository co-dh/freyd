# `scripts/cd-check` asks this file for each one's record, in the note's document order — so

# counts the commutative canvases of that display, in the order the display draws them.  `-` as the

# panel to, and only the panel's own geometry is checked.

# selector off that call (`--input cdscan=1` brackets its canvases), so the note is its one source.

# A row `- | <selector> | <reference>` names a panel the note draws NO canvas for: it is exported and
